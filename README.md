# Foundry VTT — Community Projects

### Open-source modules, Spanish translations and compatibility tools

Welcome! This GitHub profile hosts community-driven projects for **Foundry Virtual Tabletop**, with a special focus on **Dungeons & Dragons 5e**.

My goal is to improve accessibility for Spanish-speaking players and Game Masters while developing tools that simplify game preparation, maintenance and compatibility.

### Projects

| Project | Description |
|---|---|
| [D&D 5e Compatibility Checker](https://github.com/foundryvtt-sinregistrar/dnd5e-compatibility-checker) | Compatibility checking and reporting tools. |
| [Spell Advancement](https://github.com/foundryvtt-sinregistrar/dnd5e-spell-advancement) | Improvements to spellcasting character advancement. |
| [D&D 5e 2024 Cleric Domains](https://github.com/foundryvtt-sinregistrar/dnd5e-2024-cleric-domains) | Cleric domain content for the 2024 rules. |
| [Spanish Translation — Phandelver & Below](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-phandelver-below-es) | Spanish localization support. |
| [Spanish Translation — Tomb of Annihilation](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-tomb-annihilation-es) | Spanish localization support. |
| [Spanish Translation — Wizard Schools 2024](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-wizard-schools-2024-es) | Spanish localization support. |

Explore the repositories for installation instructions, requirements, and compatibility information.

### Support development

These projects are maintained voluntarily. If you find them useful, you can help support ongoing maintenance, bug fixes, documentation and compatibility updates.

# Proyectos de Foundry VTT

### Módulos de código abierto, traducciones al español y herramientas de compatibilidad

¡Bienvenido! Este perfil reúne proyectos comunitarios para **Foundry Virtual Tabletop**, especialmente relacionados con **Dungeons & Dragons 5e**.

El objetivo es facilitar el acceso al contenido en español y desarrollar herramientas que simplifiquen la preparación, el mantenimiento y la compatibilidad de las partidas.

### Proyectos

| Proyecto | Descripción |
|---|---|
| [Comprobador de compatibilidad D&D 5e](https://github.com/foundryvtt-sinregistrar/dnd5e-compatibility-checker) | Herramientas para comprobar y documentar la compatibilidad. |
| [Mejoras de progresión de conjuros](https://github.com/foundryvtt-sinregistrar/dnd5e-spell-advancement) | Mejoras en la subida de nivel de personajes lanzadores de conjuros. |
| [Dominios de clérigo 2024](https://github.com/foundryvtt-sinregistrar/dnd5e-2024-cleric-domains) | Contenido de dominios de clérigo para las reglas de 2024. |
| [Traducción de Phandelver & Below](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-phandelver-below-es) | Localización al español. |
| [Traducción de Tomb of Annihilation](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-tomb-annihilation-es) | Localización al español. |
| [Traducción de Escuelas de Magia 2024](https://github.com/foundryvtt-sinregistrar/translate-dnd5e-wizard-schools-2024-es) | Localización al español. |

Consulta cada repositorio para conocer sus instrucciones de instalación, requisitos y compatibilidad.

### Apoya el desarrollo
